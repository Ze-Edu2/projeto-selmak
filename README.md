# Selmak Balanças - Agenda de Visitas 🛠️

Este projeto é uma aplicação moderna de gerenciamento de tarefas e agenda de visitas técnicas focada no setor de manutenção, calibração e comercialização de balanças. 

Desenvolvido com o objetivo de aprimorar meus estudos práticos no ecossistema web atual e, ao mesmo tempo, atender a uma necessidade real de operação da **Selmak Balanças**.

## ✨ Funcionalidades Principais

*   **📅 Agenda Interativa:** Visualização e controle de visitas agendadas por data com calendário fluído.
*   **⚙️ Checklist Técnico de Balanças:** Formulário integrado para registrar a calibração de balanças (capacidade, resolução, modelo e testes de zero, carga e excentricidade).
*   **👥 Diretório de Clientes:** Cadastro e sincronização automática de dados de contato e estatísticas de visitas por cliente.
*   **📊 Painel de Métricas (Stats):** Visão geral rápida sobre visitas pendentes, em execução e concluídas.
*   **💾 Sincronização Híbrida:** persistência em LocalStorage com backend em tempo real.

---

## 🚀 Tecnologias Utilizadas

*   **Frontend:** React 19 + TypeScript + Vite para uma interface rápida e tipagem estática robusta.
*   **Estilização:** Tailwind CSS (v4) responsável por um design escuro moderno, elegante e totalmente responsivo.
*   **Ícones:** Lucide React para elementos visuais consistentes e dinâmicos.
*   **Banco de Dados & Sync:** **Supabase** integrado para fornecimento rápido de banco de dados relacional e serviços de sincronização.
*   **Inteligência Artificial:** Desenvolvido em coprodução direta com o **Google AI Studio (Google Studio I.A)**, agilizando as tomadas de decisões arquiteturais e design de código.
*   **Hospedagem & Deploy:** Implantado e distribuído de forma contínua através da **Vercel**.
